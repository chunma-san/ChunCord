ChunCord integration maintained by [chunma-san](https://github.com/chunma-san).

Open Settings > ChunCord > Plugins > CustomProfileWidgets to enable it and open its widget manager. Custom widgets render only in your own client; other Discord users do not receive them. Remote images contact the image host; local image uploads stay in your plugin settings. Use the editor's JSON export to back up widgets.

This tracked userplugin survives Equicord synchronization. Upstream updates require a reviewed source import rather than downloading executable code at runtime.
